Moment Pro Camera II
★★★★★★★★★★4.5App Store ↗

Onboarding Guide & Action Plate Customization

Moment Pro Camera II is an iPhone camera app with manual controls for settings like exposure, shutter speed, and ISO. These features aren’t always obvious when you first open the app, so I built the full onboarding guide to help users discover them and learn how to use them.

The main challenge was highlighting controls that users can rearrange in the Action Plate. The guide needed to find each control in its current position, rather than rely on fixed coordinates, so it would still work with a customized layout.

I built the Action Plate Browser, where users can choose between different Action Plates and customize each one by changing its color and rearranging or removing controls.

Some Action Plates have controls with custom shapes, which made their UI more challenging to implement. I used SwiftUI’s Path API to draw those shapes.
